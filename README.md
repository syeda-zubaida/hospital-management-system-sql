# Hospital Management System | SQL

This project is a relational database analysis project built using **MySQL** and **MySQL Workbench**.

The goal was to design a structured hospital database and use SQL queries to analyze operational and patient-related data.

## Project Overview

The database contains 8 related tables:

- Hospitals
- Doctors
- Patients
- Appointments
- Departments
- Medications
- Prescriptions
- Rooms

The project includes database creation, sample data insertion, relationship validation, and analytical SQL queries.

## Key SQL Skills Used

- Joins
- Common Table Expressions (CTEs)
- Subqueries
- Aggregations
- Window Functions
- GROUP BY
- ORDER BY
- Date Functions
- CASE-based analysis
- Relational Database Design

## Analysis Performed

The SQL queries were used to analyze:

- Appointment activity and trends
- Doctors and specialties
- Patient appointment history
- Prescription frequency
- Medication usage
- Hospital staffing
- Department distribution
- Room capacity
- Monthly appointment changes
- Hospital-level performance patterns

## Project Highlights

- Designed an **8-table relational database**
- Worked with **120 patients**
- Analyzed **100 appointments**
- Included **30 doctors**
- Included **62 medications**
- Analyzed **77 prescriptions**
- Used advanced SQL techniques including **CTEs and window functions**
- Added bonus analysis such as **month-over-month appointment trends**
